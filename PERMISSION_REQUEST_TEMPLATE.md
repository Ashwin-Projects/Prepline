# Written permission request — Prepline research dataset

**Subject:** Permission request to use short interview-experience topic summaries for academic research

Hello Jointaro/Taro team,

I am working on Prepline, an academic project at Vellore Institute of Technology that compares computer-science curriculum topics with software-engineering interview topics. I would like to ask for written permission before using any material from your interview-experience pages.

The intended use is limited to:
- recording short factual summaries of interview topics (not republishing full posts or personal details);
- mapping those summaries to a versioned computer-science topic taxonomy;
- evaluating keyword matching, TF-IDF, and sentence-embedding methods for an academic project;
- storing the approved short summaries, source URLs, license/permission evidence, and evaluation labels in a public GitHub repository.

Please confirm in writing whether this use is permitted, including storage and public redistribution of short derived topic summaries and evaluation labels. If permission is conditional, please specify the permitted scope, attribution format, retention limits, and any restrictions on public repository publication. I will not use automated scraping or bulk extraction unless you explicitly authorize it.

If this use is not permitted, I will exclude your material from the production dataset. I would appreciate a link to any applicable dataset license or research-use policy.

Thank you for your time.
